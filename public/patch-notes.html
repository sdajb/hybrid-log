Hybrid Log Web 0.15.3

Clean GitHub Pages deployment

0.15.3 deployment cleanup

GitHub Pages now has one deployment path only: Vite source → dist/ → GitHub Actions Pages. Old root-level production assets and the custom root-copy build wrapper were removed.

A startup fallback now displays a visible diagnostic instead of an empty page if the JavaScript bundle fails before React mounts.

0.15.2 hotfix

Fixed a root export issue that caused the deployed app to render a blank page even though the build succeeded. App is again the default React export; the Portfolio Tour remains a normal child component.

First-visit tour

New visitors now get a short four-step product tour before exploring the interactive sample-data demo.

  1. Hybrid Log — the product idea and Track → Plan → Learn → Adjust loop.
  2. Product Map — what TODAY, ACT, EAT, PLAN and PROGRESS each do.
  3. Build — React, Vite, Capacitor, local-first storage and core product logic.
  4. Demo Mode — explains the sample data and invites the visitor to explore.

One-time behaviour

After the visitor selects Skip or Explore Hybrid Log, the tour is marked as seen and no longer opens automatically.

It can be replayed from Settings → Portfolio Demo → Replay Portfolio Tour.

Still included

  • English default for fresh visitors
  • Relative-date portfolio sample data
  • PORTFOLIO DEMO · SAMPLE DATA badge
  • Reset Demo Data
  • GitHub Pages / PWA safe-area support
