Hybrid Log Web 0.15.0

Portfolio Demo release

What changed

  • English is the default language for fresh web visitors.
  • Fresh visitors automatically receive realistic sample data.
  • Today, Act, Eat, Plan and Progress are populated immediately.
  • Demo dates are relative to the current day.
  • The app is clearly marked PORTFOLIO DEMO · SAMPLE DATA.
  • The startup patch-note popup has been removed.
  • Settings includes Reset Demo Data and a compact tech summary.

Demo coverage

The sample dataset demonstrates nutrition tracking, strength and running logs, weekly planning, body composition trends, TDEE history and daily recovery/check-ins.

Stack

React · Vite · Capacitor · Local-first storage · Android + Web/PWA
