# Hybrid Log Web 0.15.0 — Portfolio Demo

## Portfolio-focused web release

This release separates the public web experience from the personal Android experience.

### Changes

- English is now the default language for fresh web visitors.
- Fresh visitors receive realistic sample data automatically.
- Today, Act, Eat, Plan, and Progress all open with populated data.
- Demo dates are generated relative to the current day, so the portfolio does not look stale.
- The header clearly labels the site as `PORTFOLIO DEMO · SAMPLE DATA`.
- Automatic startup patch-note popups were removed from the portfolio build.
- Patch notes remain available from Settings.
- Settings now includes `Reset Demo Data`.
- Settings includes a compact product/tech summary:
  - React
  - Vite
  - Capacitor
  - Local-first storage
  - Android + Web/PWA
- Existing GitHub Pages root deployment, Node 24 workflow, PWA paths, and safe-area fixes remain in place.

## Demo profile

The included sample dataset demonstrates:

- calorie and macro tracking
- completed strength sessions
- running logs
- a populated weekly training plan
- body-weight and body-fat trends
- TDEE history
- daily check-ins and recovery days

All sample dates are generated relative to the current date.
